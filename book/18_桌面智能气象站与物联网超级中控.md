## 🎓 毕业设计实战总览

历经 **18 个关卡的攻坚克难**，你从一个连串口波特率、GPIO 高低电平都不了解的纯小白，一步一个脚印，亲手攻克了：
* **基础硬件外设**：LED、PWM 呼吸灯、按键消抖、GPIO 中断、FreeRTOS 双核队列；
* **传感器与通信总线**：WS2812 幻彩灯带、ADC 采样、NTC 测温、超声波测距、I2C 总线、DHT11 温湿度；
* **存储与图形渲染**：NVS 偏好设置、ST7789 彩屏驱动、LVGL v9 触控 GUI、TF 卡 FATFS 文件系统；
* **物联网与无线互联**：Wi-Fi STA 联网、SNTP 授时、HTTP 天气时钟、MQTT 阿里云 IoT 双向通信、BLE 蓝牙遥控；
* **高级电源与架构**：Deep-sleep 微安级休眠、BSP 三层解耦架构与事件总线！

在全书的终极毕业关卡中，我们将把**所有 18 个关卡学到的硬核技能熔炼为一体**，打造一个属于你自己的**商业级桌面多功能智能气象站与物联网超级中控台**！

## 18.2 📚 终极综合工程模块字典与技术全景速查

| 功能中枢 | 核心驱动 / 协议 | 对应硬件引脚 / 模块 | 核心职责 |
| :--- | :--- | :--- | :--- |
| **网络时钟中枢** | Wi-Fi STA + SNTP | ESP32 射频天线 | 毫秒级网络对时，生成标准北京时间戳 |
| **云端物联网中枢** | MQTT Client (QoS 1) | 阿里云 / EMQX 物联网 Broker | 每 3 秒上传环境遥测数据，监听远程控制指令 |
| **传感器感知中枢** | ADC / I2C / 单总线 | GPIO27(LED) / GPIO39(按键) / NTC / 超声波 | 采集室内外温湿度与距离，计算剩余内存 |
| **软件工程架构** | BSP 分层 + FreeRTOS | 双核 240MHz + 2MB PSRAM | 模块完全解耦，内存零泄露，高并发稳定运行 |

## 18.4 终极代码实战第 2 步：桌面智能气象站全栈总成 (Full Featured Smart Station)

> 📁 **配套源码文件**：[`code/18_final_station_hub/02_full_featured_smart_station.c`](../code/18_final_station_hub/02_full_featured_smart_station.c)  
> ⚡ **一键切换运行**：在终端运行 `./switch_code.sh 18 2 --flash` 即可秒级切换并自动烧录！

```c
// 核心运行循环：自动授时、传感器融合与 MQTT 实时双向通信
static void hub_telemetry_task(void *pvParameters)
{
    while (1) {
        update_current_time_str(s_hub_state.time_str, sizeof(s_hub_state.time_str));
        ESP_LOGI(TAG, "⏰ 当前时间: %s | 气温 %.1f°C | 湿度 %.1f%% | 测距: %.1fcm | 内存: %luKB",
                 s_hub_state.time_str, s_hub_state.temperature, s_hub_state.humidity,
                 s_hub_state.distance_cm, s_hub_state.free_heap_kb);

        if (s_mqtt_connected) {
            esp_mqtt_client_publish(s_mqtt_client, "esp32/smart_hub/telemetry", json_payload, 0, 1, 0);
        }
        vTaskDelay(pdMS_TO_TICKS(3000));
    }
}
```
