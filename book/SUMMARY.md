# 📖 ESP32 物联网实战闯关指南 (开源电子书目录)

> 本书依托 ESP32 (8MB Flash + 2MB PSRAM) 综合开发套件，以“通关闯关”为脉络，系统化讲解 ESP-IDF v6、FreeRTOS、现代 C 语言与嵌入式 GUI (LVGL v9)、网络协议与传感器驱动开发。

---

## 🗺️ 学习导读：小白成神之路（6 个阶段的通俗逻辑）

很多初学者看到密密麻麻的技术名词容易感到无从下手。本书将学习路径拆解为了 **6 个由浅入深的阶梯阶段**，用最通俗的生活比喻告诉你每个阶段在学什么：

| 阶段 | 阶段名称 | 用大白话解释这个阶段在学什么？ | 学完达到的效果 |
| :---: | :--- | :--- | :--- |
| **阶段一** | **见光验证与数字控制**<br>*(第 01~03 关)* | 学会让单片机“说话”（串口打印）、“动手动脚”（点灯/呼吸灯）、“长出触觉和眼睛”（按键与红外感应）。 | 掌握最基础的数字电平（0 和 1）控制。 |
| **阶段二** | **中断与操作系统进阶**<br>*(第 04~06 关)* | 告别让单片机“傻傻死等”，学会**“硬件中断打断”**（按键一按立刻响应）；学会 **FreeRTOS 多任务分工**（类似一个人一边唱歌一边跳舞）；学会用硬件外设驱动 **WS2812 炫酷彩虹灯**。 | 掌握单片机程序员最核心的“多任务管理与底层中断”内功。 |
| **阶段三** | **传感器大集结与总线**<br>*(第 07~08 关)* | 现实世界的温度、距离不是简单的 0 和 1。这一阶段学会**量体温 (NTC ADC)、量距离 (超声波)、量温湿度 (DHT11)**，并搞懂芯片之间交流的语言（I2C 总线）。 | 单片机能测量现实世界中连续变化的物理量。 |
| **阶段四** | **本地存储与华丽触摸屏**<br>*(第 09~11 关)* | 学会让单片机断电也**“不失忆”（NVS 存储密码）**；学会驱动板子上的 **1.69寸彩色大屏幕**；学会用手机级 UI 框架 **LVGL** 做出可以用手指滑动的现代化界面！ | 你的开发板拥有了像智能手表一样的华丽触摸界面。 |
| **阶段五** | **连接万物与手机互联**<br>*(第 12~14 关)* | 让开发板连上家里的 **Wi-Fi** 自动对时和查天气；学会 **MQTT**（无论你在哪，用手机 App 远程遥控家里的灯）；学会 **BLE 蓝牙**（用微信小程序一键扫码连接开发板）。 | 跨入真正的“物联网（IoT）与智能家居”大门。 |
| **阶段六** | **扩展、低功耗与毕业大作**<br>*(第 15~17 关)* | 插上 **TF 内存卡** 做电子相册；学会电池供电的**低功耗省电休眠**；最后把前面 16 关所学的所有技能全部融合，做出**【桌面智能气象站与物联网超级中控台】**！ | 独立完成一套可以摆在桌面上、商业级的完整软硬件毕业大作！ |
