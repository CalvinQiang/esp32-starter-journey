# 第 16 关：ESP32 低功耗电源管理与 Deep-sleep 深度睡眠唤醒 (电池省电技术)

![第16关封面插画](../docs/images/esp32_level16_cover.jpg)

## 🎯 本关学习目标

如果我们的 ESP32 项目（比如野外农田土壤墒情监测仪、家门口智能猫眼、便携式智能手表）脱离了 USB 充电线，完全依靠一块 **500mAh 的小型锂电池供电**：
* 如果 CPU 和 Wi-Fi 全速运转（电流约 150mA~240mA），电池 **2~3 个小时就会彻底耗尽关机**！
* 但如果平时让芯片进入 **Deep-sleep（深度睡眠模式）**，整机电流瞬间降至 **数微安（~5μA）**，同一块电池居然能**持续待机 1~2 年**！

完成本关卡后，你将达成以下核心成就：
1. **搞懂 ESP32 的五种电源模式**：理解 Active 正常运行与 Deep-sleep 微安级休眠的物理本质；
2. **掌握 `RTC_DATA_ATTR` 慢速内存黑科技**：单片机进入深度睡眠后 CPU 断电，睡醒后依然能记住之前的历史数据；
3. **掌握三大休眠唤醒源机制**：
   - 闹钟定时器唤醒（Timer Wakeup）；
   - EXT0 单引脚硬件电平唤醒（板载 SW3 按键低电平唤醒）；
   - EXT1 多引脚位掩码唤醒（SR602 人体红外感应高电平唤醒）；
4. **打造低功耗环境监测哨兵**：平时微安级沉睡，定时/有人靠近瞬间唤醒巡检，处理完毕重新秒级入睡！

## 16.1 什么是 Deep-sleep？为什么能省电上万倍？

```text
 ┌─────────────────────────────────────────────────────────────┐
 │                【正常运行 (Active) VS 深度睡眠 (Deep-sleep)】│
 │                                                             │
 │  1. 正常运行 (Active) ➔ 【开着引擎的大卡车】                │
 │     - 双核 CPU @ 240MHz、Wi-Fi 射频、RAM 全部通电；        │
 │     - 工作电流：~150mA - 240mA（耗电极快）。               │
 │                                                             │
 │  2. 深度睡眠 (Deep-sleep) ➔ 【拔掉钥匙只留保安值班】        │
 │     - 双核 CPU、系统 RAM、Wi-Fi/蓝牙 全部彻底断电！         │
 │     - 只有极其省电的 **RTC 超低功耗协处理器** 保持微弱供电；│
 │     - 工作电流：仅约 **5 μA（微安）**（功耗降低 30,000 倍）！│
 └─────────────────────────────────────────────────────────────┘
```

## 16.2 睡醒了怎么记住数据？`RTC_DATA_ATTR` 慢速 RAM

很多小白疑惑：**“单片机进入 Deep-sleep 后系统 RAM 断电了，普通变量全被清空了，它怎么知道自己一共被唤醒了几次？”**

ESP32 内部专门内置了 **8KB 的 RTC 慢速 RAM**：
* 只要在全局变量前面加上 **`RTC_DATA_ATTR`** 宏修饰；
* 这个变量就会被存入 RTC 慢速内存，**即使 CPU 深度睡眠断电，这个变量的数据也永远不会丢失！**

```c
// ⚡ 关键：这个变量在 Deep-sleep 睡眠期间数据完好无损！
static RTC_DATA_ATTR int s_boot_count = 0;
```

## 16.3 外部唤醒源大白话：EXT0（按键）与 EXT1（红外）

```text
 ┌─────────────────────────────────────────────────────────────┐
 │                【EXT0 唤醒 VS EXT1 唤醒】                   │
 │                                                             │
 │  1. EXT0 (单个 RTC 引脚唤醒) ➔ 相当于【大门口的专用门铃】   │
 │     - 监听单个 RTC GPIO（如 SW3 按键 GPIO39）；             │
 │     - 只要检测到低电平 0（按键被按下），芯片瞬间被叫醒！    │
 │                                                             │
 │  2. EXT1 (多个 RTC 引脚组唤醒) ➔ 相当于【全屋红外防盗网】   │
 │     - 可以同时监听多个 RTC GPIO（用位掩码 Mask 组合）；     │
 │     - 只要 SR602 人体红外感应到高电平 1，芯片瞬间被叫醒！   │
 └─────────────────────────────────────────────────────────────┘
```

### 2. 🎛️ 常用唤醒函数速查

* **① 闹钟定时器唤醒**：
  ```c
  esp_sleep_enable_timer_wakeup(5 * 1000 * 1000); // 5 秒后唤醒 (单位: 微秒)
  ```
* **② 按键 EXT0 唤醒**：
  ```c
  esp_sleep_enable_ext0_wakeup(GPIO_NUM_39, 0); // GPIO39 变低电平 0 时唤醒
  ```
* **③ 人体红外 EXT1 唤醒**：
  ```c
  esp_sleep_enable_ext1_wakeup(1ULL << GPIO_NUM_34, ESP_EXT1_WAKEUP_ANY_HIGH); // GPIO34 变高电平 1 时唤醒
  ```
* **④ 立即进入深度睡眠**：
  ```c
  esp_deep_sleep_start(); // 芯片立即断电入睡，醒来后从 app_main() 重新开始执行！
  ```

## 16.5 实战第 1 步：Timer 定时器深度睡眠与 RTC 数据保持

配置 5 秒定时器休眠，每次睡醒自增 RTC 计数器：

> 📁 **配套源码文件**：[`code/16_low_power_deepsleep/01_timer_wakeup.c`](../code/16_low_power_deepsleep/01_timer_wakeup.c)  
> ⚡ **一键切换运行**：在终端运行 `./switch_code.sh 16 1 --flash` 即可秒级切换并自动烧录！

```c
static RTC_DATA_ATTR int s_boot_count = 0;

void app_main(void)
{
    s_boot_count++;
    ESP_LOGI(TAG, "🎉 [芯片唤醒] 累计唤醒次数: %d", s_boot_count);

    // 设置 5 秒定时器
    esp_sleep_enable_timer_wakeup(5 * 1000 * 1000);
    // 立即进入深度休眠
    esp_deep_sleep_start();
}
```

## 16.6 实战第 2 步：EXT0 / EXT1 外部按键与红外传感器硬件唤醒

不设定时器，芯片无限期沉睡，直到人工按下 SW3 按键（EXT0）或有人在红外传感器前走过（EXT1）时瞬间被叫醒：

> 📁 **配套源码文件**：[`code/16_low_power_deepsleep/02_ext0_ext1_wakeup.c`](../code/16_low_power_deepsleep/02_ext0_ext1_wakeup.c)  
> ⚡ **一键切换运行**：在终端运行 `./switch_code.sh 16 2 --flash` 即可秒级切换并自动烧录！

```c
// 1. 配置按键唤醒 (EXT0)
esp_sleep_enable_ext0_wakeup(GPIO_NUM_39, 0);

// 2. 配置红外唤醒 (EXT1)
esp_sleep_enable_ext1_wakeup(1ULL << GPIO_NUM_34, ESP_EXT1_WAKEUP_ANY_HIGH);

// 3. 进入深度睡眠
esp_deep_sleep_start();
```
